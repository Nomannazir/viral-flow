# system prompt for Claude Haiku — script generator SYSTEM = """ You are a viral short video scriptwriter. Output ONLY valid JSON, no markdown. Rules: - Hook must stop scroll in first 2 seconds — use pattern interrupt or open loop - Build section delivers value fast — one insight per 5 seconds - CTA triggers comments or saves — never say "like and subscribe" - Tone: conversational, direct, slightly urgent - Platform: {platform} | Length: {duration}s | Niche: {niche} Output format: { "hook": "first 2-3 seconds exactly", "build": ["scene 1 text", "scene 2 text", ...], "cta": "final 3 seconds", "title": "YouTube/TikTok title with keyword", "description": "150 word SEO description with affiliate placeholder", "hashtags": ["#tag1", "#tag2", ...], "thumbnail_prompt": "FLUX image generation prompt for thumbnail" } """ USER = f"Topic: {topic}\nVirality score: {score}\nHook type: {hook_type}" response = anthropic.messages.create( model="claude-haiku-3-5-20241022", max_tokens=800, system=SYSTEM, messages=[{"role": "user", "content": USER}] ) script = json.loads(response.content[0].text)
FFmpeg assembly command (Python)
# assemble_video.py — stitch clips + audio + captions import subprocess, json def assemble_video(clips, audio_path, captions, output_path): # 1. Create concat file for FFmpeg concat = "\n".join([f"file '{c}'" for c in clips]) with open("/tmp/concat.txt", "w") as f: f.write(concat) # 2. Stitch clips + mix audio + add captions + resize to 9:16 cmd = [ "ffmpeg", "-f", "concat", "-safe", "0", "-i", "/tmp/concat.txt", "-i", audio_path, "-vf", f"scale=1080:1920:force_original_aspect_ratio=increase," f"crop=1080:1920,subtitles={captions}:force_style='FontSize=18," f"PrimaryColour=&H00FFFF00,Bold=1,MarginV=80'", "-c:v", "libx264", "-preset", "fast", "-crf", "23", "-c:a", "aac", "-b:a", "192k", "-shortest", "-y", output_path ] subprocess.run(cmd, check=True) return output_path

KEY RISKS & HOW TO BEAT THEM
KNOW BEFORE YOU BUILD
Risk: Low video quality at start. Your first 20–50 videos will be rough. This is normal. Ship anyway — early videos get fewer views and give you time to tune prompts before the algorithm finds you.
Fix: Tight feedback loop. Review every video's 48h retention curve. If below 40%, identify which second viewers dropped — then fix that section of the script template. One tweak per week compounds fast.
Risk: TikTok API rejection. TikTok is strict with API access. Apply early but have Publer ready as immediate fallback. Manual posting for the first 2 weeks is fine — you only have 3–5 videos/day at that stage.
Fix: Publer + schedule block. Publer.io ($15/mo) supports TikTok, Instagram, and YouTube scheduling. Build automation to push video + metadata to Publer via API — nearly as good as direct posting.
Risk: fal.ai costs spiral. Video generation is the biggest cost. Without controls, 20 videos/day can hit $400+/mo on Kling alone.
Fix: Hard cost cap in n8n. Add a daily spend counter in Supabase. When fal.ai spend hits $8/day, switch all remaining jobs to WAN 2.1 + Pexels stock only. Never exceed $200/mo without confirmed revenue first.
Risk: All content feels samey / AI-detectable. If every video starts with "Most people don't know..." the algorithm and audience will tune out.
Fix: Hook rotation + persona variation. Keep a library of 20+ hook templates. Rotate by niche and time. A/B test weekly. Add occasional "human element" frames (sourced B-roll with real people) to break the AI-generated visual pattern.
